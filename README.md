## Smart Spend Analytics: A Behavioral Finance Dashboard — Project 3

![images](/images/project3_image5.png)
![image2](/images/project3_image1.png)
A personal finance dashboard built from a raw, unfiltered bank statement export — no pre-cleaned sample data. Covers overall financial position (spending, income, net cashflow, current balance), a Pareto analysis identifying that just 7 merchants account for 80% of spending, recurring vs. one-off expense detection, and weekday/weekend and day-of-month spending behavior patterns. Includes a two-tier Power Query merchant-normalization pipeline (keyword matching + word-overlap grouping) that collapsed 150+ raw merchant names down to ~77 canonical ones, plus intermediate DAX (Pareto ranking, running totals, recurring-cost detection) built on a proper star schema with a custom Date dimension.
