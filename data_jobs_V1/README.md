# 📘 Data Jobs Analytics Dashboard – Project Summary
## Introduction
This project Data Jobs Analytics Dashboard is a full end to end Power BI Business Intelligence solution designed to analyze global job market trends across data focused roles. This project transforms raw job posting data into clear, actionable insights for **recruiters, job seekers, hiring managers, and workforce analysts**, enabling fast, data driven decision making.

The dashboard built with purpose to provides a unified view of job demand, *salary expectations, hiring patterns, benefits, and platform distribution*—solving the challenge of scattered and inconsistent job market information.

## Background
The rapid growth of the data industry has created a fragmented job market landscape. Job seekers struggle to understand salary expectations, recruiters need competitive benchmarking, and analysts require reliable trend data.

This project addresses these gaps by centralizing key market indicators such as:

- Role demand across the industry

- Salary variations between technical and business facing roles

- Global hiring distribution

- Employment benefits and remote work availability

- Platform level recruitment activity

- Year over year job posting trends

The dashboard uses interactive filtering and drill through navigation to help users explore the market at both macro and role specific levels.

## Technologies Used
Power BI Desktop: Dashboard development & visualization

Power Query: ETL, data cleaning, shaping, and transformation

DAX : KPI calculations, implicit measures, and analytical logic

Star Schema Data Modeling : Fact/dimension design for scalability

Excel/CSV Dataset : Source data for job postings

Data Model Structure

Fact Table: job_postings_fact

Dimension Tables: company_dim, date_dim, skills_dim, skills_job_dim, schedule_type

This model ensures optimized performance, reduced redundancy, and efficient analytical queries.
